# 📚 Weekly Learning Themes - How It Works

## The New System

Instead of random daily topics, your agent now rotates through **6 major themes** (2 weeks each), with **deep daily dives** into specific subtopics.

### Why This Works Better
- **Continuity:** Each day builds on the previous → better retention
- **Depth:** 7 days to master ONE broad concept vs. touching random topics
- **Engagement:** You develop genuine expertise, not surface knowledge
- **Long-term thinking:** Themes like "Macroeconomics" and "Investing History" compound over time

## 🎯 Each Daily Report Includes

When your agent runs, the **Learning Recommendation** section will contain:

1. **Today's Specific Focus** - Which part of the theme you're exploring
2. **Why This Aspect Matters** - Connection to investing/tech/current events
3. **Core Concept (5-minute explainer)** - First principles explanation
4. **The Counterintuitive Truth** - What most people get wrong
5. **3 Resources** - Entry point → Deep dive → Expert level
6. **Question to Sit With** - Reflection for the day
7. **Practical Connection** - How it affects your actual decisions
8. **Tomorrow's Preview** - What's coming next (build curiosity)

## 💡 Pro Tips

1. **Archive as you go:** Each week when the theme rotates, copy key learnings to LEARNINGS.md
2. **Build your own context:** Add what you learn to MEMORY.md - the agent reads it every run
3. **Cross-reference:** When a daily topic connects to your investments, note it in CONTEXT.md
4. **Depth over breadth:** Spend the full week on each theme. You'll understand it 10x better than random topics
